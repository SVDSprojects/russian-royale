# Управление XP

В разделе админки «Пользователи» кнопка «Изменить XP» открывает форму начисления или списания. Есть поиск по имени, почте и публичному ID, текущее значение, предварительный итог и необязательная причина. Нажатие кнопки применения выполняет операцию без дополнительного подтверждения. При ошибке запрос можно повторить с прежним номером операции.

POST /api/admin/users/:id/xp доступен только роли admin. Поля: delta — ненулевое целое от −1000000 до 1000000, commandId — уникальный номер, reason — до 300 символов. Отрицательный итог запрещён. Запись результата и журнал действий выполняются в одной транзакции. Повтор того же номера операции тем же администратором возвращает прежний результат; изменение пользователя, суммы или причины с прежним номером отклоняется. Параллельные разные операции применяются последовательно к актуальному значению XP.

Корректируется users.xp, влияющий на уровень и рейтинг. Уже купленные подарки и история покупок сохраняются. Доступный баланс покупок остаётся max(0, XP минус ранее потраченный XP); снижение XP ниже суммы покупок не возвращает потраченные баллы. В журнале видны значения до и после, величина изменения, причина и администратор.

Проверено: ограничения прав для игрока, редактора и модератора, повтор и конфликт номера операции, целые значения и границы, запрет отрицательного XP, параллельное начисление, изменение собственного XP администратором, сохранность подарков и баланса. Браузерный сценарий проходит начисление и списание в форме, включая просмотр на телефоне. Выполнены сборка и проверка типов Cloudflare.
