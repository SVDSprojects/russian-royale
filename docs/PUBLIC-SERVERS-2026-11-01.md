# Общие серверы игр 1 ноября 2026

Созданы стабильные идентификаторы public-spy, public-mafia, public-bunker, public-durak, public-impostor, public-whoami, public-alias, public-roulette, public-jeopardy, public-broken-text. При первом авторизованном обращении серверы создаются, пользователь автоматически вступает в них. Таблица rr_public_servers связывает игру и сервер, повторные обращения не сбрасывают названия. Ранее созданные частные серверы и данные сохранены, но не предлагаются в новом списке. Новые пользовательские серверы запрещены (403), комнаты привязаны к серверу соответствующей игры. Общие серверы нельзя удалить или приглашать на них по закрытым ссылкам.

PATCH /api/admin/servers/:id принимает name длиной 1–80, доступ только admin. Модератор может видеть список, изменение отклоняется. Админка содержит поля переименования. Доступность общих серверов делает новые комнаты общедоступными зарегистрированным игрокам; игровые секреты по-прежнему проецируются для конкретного участника.

Проверено: TypeScript приложения и Cloudflare; сборка; два интеграционных теста Node/Cloudflare JsonRouter; браузерный сценарий двух аккаунтов без приглашений, отсутствие создания сервера, десять серверов, выбор нужного сервера всеми девятью импортированными играми. Прежние тесты, ожидающие создание частных серверов, требуют миграции на новую модель и не являются проверкой текущего поведения.
