# Царукян — вариант 3

Создан встроенным image_gen по визуальному образцу из пользовательского видео. Это собственная иллюстрация, не официальный подарок Telegram и не блокчейн NFT.

Промпт: 4×4 последовательных кадра одной фигурки Армана Царукяна в стиле объёмных мультяшных коллекционных подарков Telegram; большая голова, маленькое спортивное тело, короткие тёмные волосы, аккуратная борода, без татуировок, чёрные перчатки с красными манжетами, красные шорты с армянским триколором. Фронтальная неподвижная камера, одинаковый масштаб и оливковый фон, без надписей и логотипов. Руки поднимаются в победном жесте, подмигивание, кивок, возвращение в исходную позу. Простые округлые формы и мягкий объём, без реалистичных сложных текстур.

16 нарисованных кадров упакованы в цикл 3,2 секунды с интерполяцией до 25 кадров/с. При отключении движения интерфейс показывает неподвижный первый кадр. Интерполяция не является полноценной трёхмерной моделью; возможны небольшие изменения контуров между ключевыми кадрами.

- tsarukyan-preview.gif — просмотр анимации.
- tsarukyan-animated.webp — версия для сайта.
- tsarukyan-sprites.webp — исходная сетка кадров.
