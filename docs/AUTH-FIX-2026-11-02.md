# Исправления регистрации и проверка почты 2 ноября 2026

Тёмная тема временно отключена на всём сайте по запросу владельца. Старые настройки dark/system больше не включают нечитаемую палитру. Форма регистрации/входа/восстановления дополнительно получила собственные светлые контрастные стили полей, вкладок и сообщений.

Запрос кода регистрации на уже занятый адрес теперь отвечает 409 с предложением войти или восстановить пароль, вместо молчаливого отсутствия отправки. Восстановление для неизвестного адреса сохраняет одинаковый ответ, чтобы не раскрывать наличие аккаунта. Регистрация новых пользователей и восстановление для существующих используют разные коды.

На живом сайте отправлено проверочное письмо восстановления на адрес владельца. Brevo вернул messageId, в отчёте событий для адреса зафиксировано delivered. Это подтверждение доставки почтовому серверу, не прочтения письма пользователем. Содержимое кодов и API-ключи не выводятся в журнал; диагностика содержит только тип события, техническую причину и идентификатор сообщения. Проверки доставки используют официальную статистику Brevo https://developers.brevo.com/reference/get-email-event-report.

В архив передачи входят исходники, ресурсы, тесты и инструкции; рабочая база и секреты не передаются. Ключ Brevo и служебные параметры нужно подключать отдельно на собственном хостинге получателя.
