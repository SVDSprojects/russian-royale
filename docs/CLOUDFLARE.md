# Постоянное размещение Cloudflare

Адрес: https://russian-royale.russian-royale.workers.dev

Проект опубликован в аккаунте владельца. Компьютер и туннель для доступа не нужны. Платный тариф не подключался. Бесплатные квоты Cloudflare ограничивают нагрузку; при их исчерпании запросы могут временно перестать выполняться. Это не гарантия доступности 24/7.

## Устройство

Страницы из `dist` обслуживает Workers Assets. Серверная логика общая с локальной версией; адаптер JSON-маршрутов находится в `cloudflare/router.ts`. Один SQLite Durable Object `Royale/main` хранит аккаунты, учебный контент, прогресс и игровое состояние. Синхронные транзакции выполняет `storage.transactionSync`. Серверные сроки игры поддерживают alarms; клиент получает уведомления через авторизованный long polling. Секретные роли не входят в уведомления.

Загруженные изображения хранятся частями по 256 КБ в той же базе, без отдельной платной подписки R2. Облачный обработчик проверяет тип и размеры растра, лимит 2 МБ/16 МП, запрещает SVG и выдаёт файлы с `nosniff` и ограничивающим CSP. В отличие от локального Sharp он сохраняет исходные байты, без изменения размера или перекодирования.

## Обновление

Из каталога проекта с Node 24 и установленными зависимостями:

```powershell
pnpm build
pnpm exec tsc --noEmit -p cloudflare/tsconfig.json
pnpm exec wrangler deploy
```

Для подключения владельца: `pnpm exec wrangler login`. OAuth хранит официальный Wrangler вне репозитория; пароли и токены в исходники не добавлять. `.env` относится к локальному серверу, в облако он не публикуется. Рабочие настройки публикации — `wrangler.jsonc`. Имя класса, namespace, имя объекта `main` и историю миграций сохранять: смена идентичности объекта откроет другую базу.

## Перенос 29 октября 2026

Перенесены 4 аккаунта и 1 комната вместе с остальными таблицами. Локальная база оставлена как архив, согласованная копия сохранена в `data/backups`. Загруженных пользователями картинок на момент переноса не было. Пароли сохранились; на новом домене потребуется повторный вход. Старые изменения в локальной базе больше не синхронизируются с облаком.

Одноразовый маршрут импорта удалён из рабочего Worker после переноса, временный ключ Cloudflare удалён. `scripts/migrate-cloudflare.ts` сохраняется для истории операции и не является командой обычного обновления.

## Проверки

23 серверных теста общей логики, тест атомарного импорта и 4 браузерных сценария. Отдельная проверка локального Cloudflare runtime: 3 аккаунта, полный раунд, скрытые роли, чат, long polling, права, CSRF, загрузка картинки и сохранение результатов после настоящего перезапуска. Отчёты: `artifacts/cloudflare-check.json`, `artifacts/cloudflare-migration.json`. Длительная работа на пределе бесплатных квот не проверялась.

После переноса не запускайте старый локальный сервер для редактирования облачных данных. Пользуйтесь постоянным адресом и `/admin.html` с аккаунтом, которому назначена роль администратора.
