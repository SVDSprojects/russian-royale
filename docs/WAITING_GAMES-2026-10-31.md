# Приглашения в ожидающие игры

На главной над основным баннером появился блок «Скорее присоединяйтесь к игре!». Он показывает комнаты трёх сетевых игр на серверах пользователя, где есть другой участник онлайн и свободные места. Учитывается фактическое присутствие в комнате: 45 секунд для «Шпиона», 15 секунд для импортированных игр, согласно их существующим правилам связи.

Список обновляется через события сайта, каждые 10 секунд и при возврате на вкладку. Начавшиеся, полные и пустые комнаты не предлагаются. Чужие закрытые серверы недоступны. Нажатие выполняет обычное вступление с серверной проверкой доступа и версии комнаты.

Проверки: TypeScript приложения и Cloudflare, производственная сборка; серверный тест всех трёх игр, прав доступа, заполненности, смены фазы и устаревшего присутствия; браузерный тест появления приглашения без перезагрузки, входа в каждую игру, исчезновения покинутой комнаты и мобильной ширины. Снимок: `artifacts/waiting-games-mobile.png`.

Опубликована версия `b5fe29db-22d6-476b-91eb-0fa688b2a754`. На живом сайте проверены `/api/health` (200, `release: waiting-games-1`), `/api/waiting-games` без авторизации (401) и новые JS/CSS (200). Проверки входа и игровых сценариев выполнены локально; пользовательские комнаты на рабочем сайте не изменялись.

При публикации активный Durable Object сначала продолжал выполнять предыдущий код. Для применения версии использована команда `wrangler versions deploy b5fe29db-22d6-476b-91eb-0fa688b2a754@100% --durable-objects-code-update-mode immediate --yes`. Cloudflare с 30 октября откладывает обновление активных объектов по умолчанию: [официальное описание](https://developers.cloudflare.com/changelog/post/2026-10-30-durable-objects-deferred-code-updates/). При следующих публикациях проверять версию внутри ответа health, а не только заголовок внешнего Worker.
