# Работа над Русским Royale

## Общая версия
Основная ветка main содержит принятую версию сайта. Перед началом работы выполните git fetch и обновите main через git pull --ff-only. Создайте отдельную ветку для своей задачи. Не меняйте один файл одновременно в нескольких задачах без согласования.

## Передача задачи другой нейросети
Подключите репозиторий или клонируйте его в среду с доступом к Git. Передайте описание задачи и укажите: прочитай AGENTS.md и CONTRIBUTING.ru.md, создай ветку, внеси изменения, проверь их, отправь ветку и открой pull request. Нейросеть без доступа к репозиторию не сможет синхронизировать изменения автоматически.

## Проверка и публикация
Участник отправляет ветку и pull request с описанием изменений, фактическими проверками и ограничениями. Владелец или назначенный проверяющий принимает изменения в main. Публикация в Cloudflare выполняется отдельно после проверки; GitHub сам по себе не обновляет работающий сайт. Доступ к репозиторию не требует передачи ключей Cloudflare.

## Следующее продолжение в этом чате
Напишите: «Обнови код из GitHub и продолжи». Агент проверит локальные изменения, загрузит актуальные ветки и учтёт принятые правки. Изменения не появляются автоматически в уже открытом чате. Перед передачей работы сохраняйте свою ветку и отправляйте её в репозиторий.

## Локальные файлы
Не добавляйте .env, .dev.vars, .wrangler, базы, пользовательские загрузки, архивы передачи, node_modules и секреты. Схема и стартовый контент находятся в исходниках; рабочая база остаётся на хостинге.
