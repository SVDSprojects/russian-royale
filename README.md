# Русский Royale

Рабочая тестовая версия этапов **1–3**: сайт учеников, отдельная админка, редактируемый учебный контент и настоящий многопользовательский «Шпион».

## Быстрый запуск на Windows

Нужен **Node.js 24.15 или новее в ветке 24.x**. Проверить: `node --version`. Установщик Node.js включает npm. После установки откройте новый PowerShell.

```powershell
cd 'C:\Users\user\Documents\ChatGPT\Здоровье 2\russian-royale'
npm install --global pnpm@11.25.0
pnpm install --frozen-lockfile
Copy-Item .env.example .env
pnpm build
pnpm start
```

Если `.env` уже есть, сохраняйте его настройки, не заменяйте файл примером. В текущей рабочей папке зависимости уже установлены и сборка `dist/` создана. Для повторного запуска достаточно `pnpm start` или `npm start`.

Откройте:

- Сайт: **http://localhost:3001**
- Админка: **http://localhost:3001/admin.html**

Оставьте терминал открытым. `Ctrl+C` останавливает приложение. Оба интерфейса и API обслуживаются одним процессом, но имеют отдельные HTML-файлы и JS-сборки.

Вариант для разработки с автоматическим обновлением:

```powershell
npm run dev
```

Сайт и админка: `http://localhost:5173` и `http://localhost:5173/admin.html`. API работает на порту 3001, Vite перенаправляет к нему `/api` и `/uploads`. Для игр с друзьями удобнее собранная версия на порту 3001.

### База и настройки

База автоматически создаётся при первом запуске: `data/royale.sqlite`. Миграции применяются сервером. Изображения хранятся в `data/uploads`. Аккаунт Supabase, облачный проект и секретные API-ключи для этой версии **не нужны**.

Пример переменных находится в `.env.example`:

| Переменная                           | Назначение                                                                                           |
| ------------------------------------ | ---------------------------------------------------------------------------------------------------- |
| `PORT=3001`, `HOST=0.0.0.0`          | Порт и адрес прослушивания, включая локальную сеть                                                   |
| `DATABASE_PATH=./data/royale.sqlite` | Постоянный файл базы                                                                                 |
| `UPLOADS_DIR=./data/uploads`         | Каталог загружаемых изображений                                                                      |
| `PUBLIC_ORIGIN=https://ваш-домен`    | Публичный адрес для приглашений и проверки Origin; локально можно не задавать                        |
| `NODE_ENV=production`                | Защитная политика загрузки ресурсов браузера                                                         |
| `TRUST_PROXY=1`                      | Только когда перед приложением ровно один доверенный reverse proxy                                   |
| `COOKIE_SECURE=true`                 | HTTPS-only cookie; не включайте для обычного локального HTTP                                         |
| `ADMIN_BOOTSTRAP_TOKEN`              | Необязательный случайный токен от 32 символов для первоначального назначения; рекомендуется CLI ниже |

## Первый администратор и команда из четырёх человек

1. На основном сайте зарегистрируйте **свой** email и пароль от 10 символов.
2. Во втором PowerShell, из каталога проекта, выполните:

```powershell
npm run admin -- ваш@email.ru
```

3. Откройте `/admin.html` и обновите страницу. Используется тот же аккаунт и пароль.
4. Остальные участники команды регистрируются сами. В админке откройте **Пользователи** и назначьте им роль **Редактор**. Полный администратор может управлять ролями; редактор — материалами.

Команда выполняется на компьютере/сервере, где хранится база. Обычный игрок не может назначить себе права HTTP-запросом. Нет общего пароля администратора, автоматического повышения первого зарегистрированного пользователя или заранее созданных аккаунтов. Последнего администратора нельзя лишить прав через интерфейс.

Роль модератора предусмотрена, но самостоятельный интерфейс жалоб и блокировок ещё не реализован. Не назначайте её вместо редактора, если нужен доступ к учебным материалам.

## Учебные материалы

В новой базе ровно одно правило — **«Суффиксы -ЕК- и -ИК-»**, четыре упражнения и урок **«Секрет исчезающей гласной»**. Это демонстрационные материалы. Они не зашиты в игровой интерфейс и не восстанавливаются после удаления.

### Создать, изменить или удалить правило

Откройте **Админка → Правила**. Выберите материал или нажмите **Новое правило**. Укажите категорию, объяснение, примеры, типичные ошибки, сложность и игры, где его можно использовать. Для «Шпиона» оставьте отметку **Шпион**. Включите **Опубликовать материал** и нажмите **Сохранить**.

Изменения применяются после сохранения. Чтобы скрыть правило, снимите публикацию и сохраните. Кнопка **Удалить** требует подтверждения и удаляет связанные упражнения и уроки. История ответов, завершённых уроков и игр сохраняет снимки названий. Текущий раунд продолжает использовать свою тему; следующий выбирает из текущей опубликованной библиотеки.

Если нет подходящих опубликованных правил, запуск игры показывает понятную ошибку. Добавьте новое правило — менять код не требуется.

### Задания

Раздел **Задания** позволяет создавать, редактировать и удалять упражнения независимо. Поддерживаются один/несколько вариантов, буква, слово, исправление предложения, пунктуация, соответствие, ударение и текстовый вопрос. Для нескольких ответов используйте `А;В`, для соответствия — `1-А;2-Б`, описав формат ученику. Для ударения используйте однозначный формат, например номер слога. Проверка текстовых ответов точная после нормализации регистра, пробелов и Е/Ё; смысловые варианты ответа автоматически не распознаются.

Ответ и объяснение хранятся на сервере и выдаются после отправки решения. За первое правильное решение конкретного задания — 5 XP, за первое завершение урока — 20 XP. Повторный ответ или прохождение не позволяет бесконечно получать опыт. При удалении задания связанные уроки снимаются с публикации, а недействительные ссылки на него удаляются из блоков.

### Конструктор уроков

**Уроки → Новый урок**: выберите правило, добавляйте диалоги, объяснения, примеры, изображения, упражнения, проверки, эмоции и результат. Блоки можно менять местами стрелками, редактировать и удалять. В блоках упражнений выбираются задания этого правила. Для публикации урока опубликуйте правило и все используемые задания. На сайте урок проверяет ответы и показывает соответствующую эмоцию персонажа.

### Учительница

**Учительница**: загрузите PNG/JPEG/WebP отдельно для пяти эмоций, проверьте предпросмотр, измените имя и реплики, нажмите **Сохранить персонажа**. Максимум 2 МБ и 16 мегапикселей на исходный файл. Сервер декодирует и пересохраняет изображения в WebP. Прозрачные PNG/WebP сохраняют прозрачность.

Начальные изображения созданы генератором специально для проекта. Оригинальный лист — `public/assets/teacher-sheet.png`, пять отдельных состояний — `teacher-neutral.png`, `teacher-happy.png`, `teacher-strict.png`, `teacher-surprised.png`, `teacher-explaining.png`. Замена через админку не требует редактирования этих файлов или повторной сборки.

### Импорт

Раздел **Импорт** принимает JSON или CSV. Скачайте пример в интерфейсе, заполните его и выполните предварительную проверку, затем импорт. Категории должны существовать. ID категорий видны в разделе **Категории**, ID правил — в редакторе существующего правила. Правила и задания импортируйте последовательно: сначала правила, затем упражнения с полученными `ruleId`. До 500 материалов за импорт; пакет записывается транзакционно. PDF/DOCX и пробники относятся к будущему этапу.

## Как протестировать «Шпиона»

1. Зарегистрируйте три разных аккаунта. Используйте разные устройства, профили браузера или независимые приватные окна. Вкладки одного профиля делят один аккаунт.
2. **Мои серверы → Создать сервер**, например «Наш класс».
3. В разделе **Приглашения** нажмите **Новая ссылка**, скопируйте её и отправьте друзьям самостоятельно. При входе/регистрации страница приглашения сохраняется. Ссылку можно отозвать.
4. Создайте комнату «Шпион»: 3–30 участников, время обсуждения, голосования и ответа.
5. Каждый входит в комнату и нажимает **Я готов играть**. Ведущий нажимает **Начать игру**.
6. **Показать роль**: знатоки видят тему, шпион — только категорию. Общайтесь в чате, рядом или в отдельном звонке. Встроенной голосовой связи нет.
7. Таймер или ведущий открывает голосование. Каждый отправляет один голос. До окончания голосования виден факт участия, но не выбор остальных.
8. Если **больше половины всех игроков** выбрали невиновного, выигрывает шпион. Если выбрали шпиона — у него одна попытка назвать **точное название** темы. Регистр, пунктуация и дефисы не учитываются. Верный ответ — победа шпиона, неверный/нет ответа вовремя — победа знатоков.
9. При ничьей или недостаточном большинстве после всех голосов/таймера побеждает шпион. За победу — 30 XP, остальным — 10 XP, однократно за раунд.
10. Ведущий открывает **Следующий раунд**. Все вновь подтверждают готовность.

**Одно демонстрационное правило делает угадывание очевидным.** Для интересной игры добавьте несколько разных тем в одной категории. Библиотека предназначена для обучения и доступна ученикам; секретным является выбранный сервером снимок темы текущего раунда.

Обновление страницы и переподключение сохраняют роль и голоса. При выходе ведущего управление передаётся присутствующему игроку сразу; при потере соединения — после примерно 45 секунд отсутствия активности. Если все отключились, сохраняются состояние и серверные дедлайны. Во время текущего раунда новые участники ждут следующего лобби. Выйдя из комнаты, вернитесь в неё, чтобы снова участвовать.

### Друзья в одной Wi-Fi-сети

Запустите собранное приложение на `0.0.0.0:3001`. В PowerShell выполните `ipconfig` и найдите IPv4 Wi-Fi-адаптера, например `192.168.1.25`. На телефоне откройте **`http://192.168.1.25:3001`**. Если Windows спросит разрешение, разрешите Node.js доступ к **частной сети**. При необходимости откройте входящий TCP-порт 3001 для частной сети в брандмауэре.

Создавайте/копируйте приглашения, открыв сайт по этому сетевому адресу. `localhost` на телефоне означает сам телефон. Если буфер обмена недоступен на HTTP, выделите ссылку в поле и скопируйте вручную. Некоторые гостевые Wi-Fi-сети изолируют устройства друг от друга.

### Друзья через интернет

Нужен общий опубликованный адрес. Следуйте [инструкции развёртывания](docs/DEPLOYMENT.md). Эта версия требует Node-процесс и постоянный диск; размещение только `dist/` на статическом хостинге не обеспечит вход, базу и мультиплеер. Постоянный адрес: https://russian-royale.russian-royale.workers.dev. Облачная версия использует SQLite Durable Object; подробности в [инструкции Cloudflare](docs/CLOUDFLARE.md).

## PWA и устройства

Есть manifest, иконки и service worker с экраном отсутствия сети. На HTTPS приложение можно добавить на главный экран через меню Chrome/Edge или Safari «Поделиться → На экран Домой». Онлайн-вход, уроки и мультиплеер требуют связи с сервером. Секретные роли, API и персональные данные service worker не кэширует. Проверены размеры экрана ПК и телефона в Edge/Chromium; физические Android/iPhone и Safari ещё не проверялись.

**Отступление от предпочтительного стека:** использованы React/TypeScript/Vite, собственный CSS, Node/Express, SQLite и SSE. Это позволяет запустить полный сетевой MVP на Windows без аккаунтов и ключей внешнего сервиса. Supabase Auth/Realtime/Storage, PostgreSQL и RLS **не реализованы**. Права проверяются доверенным API; браузер не имеет подключения к БД. Поддерживается один серверный процесс. SSE передаёт только уведомления об изменении, после чего клиент запрашивает разрешённое ему представление комнаты.

Остальные девять игр, система дружбы, интервальное повторение, тренажёр ЕГЭ, пробные экзамены, проверка сочинений, импорт PDF/DOCX, расширенные достижения, модерация жалоб, подтверждение email и восстановление пароля пока не реализованы. Они не представлены как готовые функции. План — в [архитектуре](docs/ARCHITECTURE.md).

Внешние технические справочники: [Node.js SQLite](https://nodejs.org/download/release/latest-v24.x/docs/api/sqlite.html), [сетевые настройки Vite](https://vite.dev/config/server-options). Шрифты и иконки поставляются локально; обращения к Google Fonts не нужны.
