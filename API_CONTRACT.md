# Russian Royale MVP contract

Local-first production-capable single-node MVP: Node 24, Express 5, SQLite via node:sqlite; React/TS/Vite multi-page student index.html and admin.html. All HTTP APIs under /api, same-origin HttpOnly cookie. JSON response directly object/list; errors {error:string}. IDs strings. ISO timestamps except deadlines and serverNow milliseconds. Protected endpoints require session. All mutation requests same-origin. No mock users or rooms.

## Shared server interface

server/db.ts exports createDatabase(path): database wrapper with SQLite `.prepare(sql).get(...params)/all(...params)/run(...params)` and `.exec(sql)`, synchronous. server/app.ts exports createApp({dbPath?,testMode?,now?}={}): {app,db,close, tick, bus}. createApp calls registerGameRoutes(app, ctx) from server/game.ts. ctx = {db, requireAuth, requireRole, broadcast, now}. req.user={id,email,username,role,xp,avatar}. broadcast(): emits only invalidation, no secrets, SSE GET /api/events authenticated. now():number. Middleware throws? Route errors via exported HttpError(status,message) in server/core.ts or route-local status.

## Foundation API (backend agent owns)

POST /auth/register {email,password,username}; POST /auth/login {email,password}; both return {user}. POST /auth/logout. GET /auth/me -> {user:null|User}. GET /profile -> {user,stats:{games,wins,losses,lessons},history:[],achievements:[]}. PATCH /profile {username,avatar?}. GET /leaderboard -> User[]. User {id,email?,username,role:'admin'|'editor'|'moderator'|'player',xp,avatar,createdAt}. Never return password hash. POST /admin/bootstrap {token} only while no admin, requires authenticated session, bootstrap token configured environment (CLI `npm run admin -- email` is preferred, no public known password). CLI promotes registered email locally.

GET /rules -> Rule[] published only; GET /rules/:id -> Rule with exercises safe (no answer); GET /categories -> {id,name}[]; GET /lessons -> Lesson[] published; GET /lessons/:id -> Lesson; GET /teacher -> Teacher. POST /exercises/:id/answer {answer:string} -> {correct,answer,explanation,xpAwarded}; POST /lessons/:id/complete -> {xpAwarded}; GET /progress -> {favorites:string[],learned:string[],answers:[],completedLessons:string[]}; POST /progress/:ruleId {favorite?:boolean,learned?:boolean}.

Rule {id,title,categoryId,category,subcategory,summary,explanation,examples:string[],mistakes:string[],images:string[],difficulty:1|2|3,games:string[],published:boolean,createdAt,updatedAt}. Exercise {id,ruleId,type:'letter'|'choice'|'multiple'|'word'|'correction'|'punctuation'|'matching'|'stress'|'text',prompt,options:string[],answer:string,explanation,difficulty,examNumber?,published}. Lesson {id,ruleId,title,published,blocks:Block[]}; Block {id,type:'dialogue'|'explanation'|'example'|'image'|'exercise'|'check'|'animation'|'result',text?,image?,emotion?:'neutral'|'happy'|'strict'|'surprised'|'explaining',exerciseId?}. Teacher {name,images:{neutral,happy,strict,surprised,explaining},phrases:{intro,correct,incorrect,complete}}.

Admin protected all /admin/* admin/editor content access; only admin users roles; moderator stats servers may later. GET /admin/stats -> {users,online,rooms,rules,exercises,lessons,games}. GET/POST /admin/rules; PUT/DELETE /admin/rules/:id. GET/POST /admin/exercises; PUT/DELETE /admin/exercises/:id. GET/POST /admin/lessons; PUT/DELETE /admin/lessons/:id. GET/POST /admin/categories; DELETE /admin/categories/:id. GET/PUT /admin/teacher. POST /admin/uploads {data:string data URL} -> {url}; accepts safe raster <=2MB, normalizes image. GET /admin/users -> User[]; PATCH /admin/users/:id {role}. GET /admin/audit -> {id,actorId,action,targetId,createdAt}[]; GET /admin/servers -> list; DELETE /admin/servers/:id admin only. POST /admin/import/preview {rules?:[],exercises?:[]} -> {valid:boolean,errors:string[],counts:{rules,exercises}}; POST /admin/import same body transactional.

Database foundation tables minimum users(id,email,username,password_hash,role,xp,avatar,created_at), sessions, categories, rules, exercises, lessons, progress, answers, lesson_completions, teacher, audit_log. Game agent creates own tables. Foundation /profile reads game_results with user_id,win,xp,created_at,topic_title,session_id; /admin/stats can query rooms(game phase stored by game). Game result unique(session_id,user_id), FK user only; history snapshots survive deleted rules. No game tables queried before registerGameRoutes.

## Multiplayer API (root owns)

GET /servers -> Server[]; POST /servers {name,description} -> Server; GET /servers/:id -> Server with members,rooms,invites for owner; POST /servers/:id/invites -> {token,url}; DELETE /invites/:token owner; GET /invites/:token public -> {server:{id,name,description},valid:true}; POST /invites/:token/join -> {serverId}. POST /servers/:id/rooms {name,maxPlayers:3..30,discussionSeconds:30..900,voteSeconds:15..180,guessSeconds:15..120} -> Room. GET /rooms/:id -> RoomView; POST /rooms/:id/join -> RoomView; POST /rooms/:id/leave -> {}; POST /rooms/:id/ready {ready:boolean}; POST /rooms/:id/start -> RoomView; POST /rooms/:id/advance -> RoomView (host discussion->voting only); POST /rooms/:id/vote {targetId} -> RoomView; POST /rooms/:id/guess {answer} -> RoomView (spy only once); POST /rooms/:id/next -> RoomView host resets to lobby. GET/POST /rooms/:id/messages {text} -> Message[]/Message, no voice built in.

Server {id,name,description,ownerId,memberCount,roomCount,createdAt,members?:{id,username,avatar,online}[],rooms?:Room[],invites?:{token,url,createdAt}[]}. Room {id,serverId,name,hostId,maxPlayers,phase:'lobby'|'discussion'|'voting'|'guess'|'finished',playerCount,discussionSeconds,voteSeconds,guessSeconds}. RoomView extends Room {players:{id,username,avatar,ready,online,voted}[],me:{role?:'spy'|'citizen',category?:string,topic?:string,voted:boolean,ready:boolean},deadline:number|null,serverNow:number,round:number,result:null|{winner:'spy'|'citizens',reason:string,topic:string,spyId:string,votes:Record<string,string>},sessionId:string|null}. No other secret properties before result. Discussion ordinary voice externally / optional room text chat. GET /events SSE invalidation event named update with data {} plus heartbeat; client refetches authorized view. Server timeouts tick every second and whenever actions/read; persisted deadlines survive restart. Offline host transfer after grace; joining new players during active forbidden; reconnecting existing active player allowed. Max30. Ready all >=3. Winner spy if no absolute majority (tie/abstentions timeout), innocent majority spy win, spy majority -> guess, correct normalized exact aliases based on topic title -> spy else citizens. Timeout guess citizens. Score once per session/user, win 30 participant10.

## Client conventions

src/api.ts root provides api<T>(path,options?), useAuth hook via AuthProvider, useLive(callback). Paths without /api prefix supplied to api. src/main.tsx root mounts StudentApp from src/student/StudentApp.tsx. src/admin-main.tsx root mounts AdminApp from src/admin/AdminApp.tsx. Each app receives no props, imports hooks from ../api and shared types from ../types. Agents may create own additional components. Student owns src/student/** and src/student.css; admin owns src/admin/** and src/admin.css. Root owns shared styles src/base.css, types, api, shells.

Read phases: foundation auth/admin/content tests must pass before game execution validation. Root builds game after foundation validates. No static fake online counts, XP or leaderboards. Upcoming nine games visibly labeled not implemented. No dead buttons. Default teacher images /assets/teacher-{emotion}.png (root generates), backend config replaceable. No content hardcoded into components. Demo seed once at DB creation, never reappears after deletion.
