# Android-приложение Русский Royale

Это онлайн-приложение для Android 8.0 и новее. Оно открывает настоящий сайт
https://russian-royale.russian-royale.workers.dev/ в системном Android WebView.
Аккаунты, почтовые коды, комнаты, друзья и игровой прогресс используют тот же сервер.
Вход в приложении выполняется отдельно от браузера. Обновления сайта появляются
при следующей загрузке страницы; переустанавливать APK ради новых вопросов не нужно.

Приложение содержит иконку, индикатор загрузки, обработку кнопки «Назад», сохранение
сеанса входа, выбор изображения для профиля и экран повторного подключения.
Внешние ссылки открываются в других приложениях. Небезопасные HTTP-загрузки и
доступ сайта к произвольным локальным файлам выключены. Ошибки сертификатов не обходятся.

## Установка

Скачайте `russian-royale-android-v1.apk` на Android, откройте загрузку и при запросе
разрешите установку из используемого браузера или файлового менеджера.
После установки запустите «Русский Royale». Нужен интернет и актуальный Android System WebView.
Это установка напрямую, без Google Play. Офлайн-игры и нативные push-уведомления
в эту версию не входят. ZIP с кодом не является установщиком приложения.

На iPhone используйте Safari → «Поделиться» → «На экран “Домой”».
APK на iPhone не устанавливается.

## Повторная сборка

Нужны JDK 17+, Android SDK (`platforms;android-35`, `build-tools;35.0.0`) и Python 3.
Укажите `JAVA_HOME` и `ANDROID_HOME`, затем выполните `python android-app/build.py`.
Результат: `exports/russian-royale-android-v1.apk`. Сборка не меняет сайт и сервер.

Для будущего обновления увеличьте `versionCode` и `versionName` в `AndroidManifest.xml`.
Сохраняйте исходный package name и ключ подписи, иначе Android не установит обновление поверх старого.
Ключ и пароль создаются в `%USERPROFILE%/.royale-signing/`, вне репозитория.
Сделайте их личную резервную копию. Никогда не кладите ключ/пароль в общую папку,
репозиторий или ZIP исходников. Передача APK и кода не требует передачи ключа.

На реальном устройстве проверьте вход, выход, почтовый код, фото профиля, экранную
клавиатуру, игру с другим участником, возврат из фона и повторное подключение после
отключения интернета. Успешная сборка сама по себе не подтверждает эти сценарии.
